Questions

Frequently Asked Questions

What happens after I purchase?
You'll receive an email within minutes with your license key and download instructions. For WordPress themes and HTML templates, log in to client.wellspringweb.com with your purchase email and license key to download your files. For Guided Setup or Done For You, we'll reach out within 1 business day to schedule your first session.
What's the difference between the platforms?
React (ChiroSite) is a full-featured web app with patient portals, online booking, payments, and staff management — best for established practices wanting a complete system. WordPress themes are ideal if you're already on WordPress or want a familiar CMS. HTML templates are the simplest option — a single file you can host anywhere with no server setup.
Do I need technical knowledge?
WordPress themes and HTML templates are designed to be set up without coding — just fill in the setup wizard. ChiroSite React requires a bit more technical comfort (deploying to Netlify, setting up Supabase) — which is why we offer the Guided Setup option where we walk you through it together.
Are there monthly fees?
No monthly fees for any one-time purchase. You will have small third-party costs depending on the template: hosting ($5–15/mo), domain ($15/yr), and for ChiroSite, optional services like Supabase and Stripe (only if you want patient portals and payments). The Done For You plan is $349/month which includes everything managed for you.
Can I use the template on multiple sites?
Each purchase is a single-site license — one license per domain. If you have multiple practice locations, you'll need a separate license for each. Contact us about multi-site pricing.
What does WellSpring Managed Hosting include?
Managed hosting ($49/month standalone, $39/month with a bundle) covers: fast web hosting for your WordPress or HTML site, SSL certificate, monthly backups, and priority email support. We handle server maintenance so you don't have to think about it. You must have an existing WellSpringWeb template license — hosting is not available as a standalone service without a template purchase.
What if I need help?
Email us at support@wellspringweb.com — we typically respond within a few hours. WordPress and HTML template purchases include basic setup support. ChiroSite Guided Setup includes 90 days of email support and 3 Zoom sessions.
